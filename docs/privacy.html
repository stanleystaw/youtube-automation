Règles de confidentialité

Dernière mise à jour : 18 septembre 2026

Qui

youtube-automation est un logiciel open source. Chaque utilisateur l’héberge lui-même (souvent via GitHub Actions) et autorise son compte Google. L’auteur du code n’a pas accès à tes données.

Données Google utilisées

Uniquement après ton consentement, et seulement sur ton compte :

  • YouTube (youtube.upload, youtube) : publier une vidéo sur ta chaîne, lire les stats de tes propres vidéos.
  • Google Drive (drive.file) : créer un dossier « Conseils » et y déposer les MP4 des clips conseils. Pas d’accès au reste de ton Drive.

Pas d’accès Gmail, Contacts, Photos, ni Drive complet.

Autres traitements (sur ton instance)

  • Textes : Google Gemini (si tu fournis une clé).
  • Génération vidéo : MagicLight (si tu fournis une clé).

Stockage

Les jetons OAuth et clés API restent dans les secrets de ton dépôt GitHub (ou un fichier .env local), jamais dans le code public. Aucune donnée n’est vendue ni utilisée pour de la publicité.

Révocation

myaccount.google.com/permissions → l’application OAuth → Supprimer l’accès.

Contact : ouvre une issue sur le dépôt GitHub du projet.
