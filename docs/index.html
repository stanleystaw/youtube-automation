Des Shorts IA,
sur ta chaîne.

Logiciel open source : chacun l’installe sur son compte Google et sa propre chaîne YouTube. Il génère des vidéos (actualité et conseils) avec une IA, publie sur YouTube, et enregistre les clips conseils sur Drive.

  • Génère des YouTube Shorts (actualité mondiale + conseils).
  • Publie sur la chaîne YouTube liée au compte autorisé.
  • Enregistre uniquement les vidéos « conseils » dans un dossier Drive dédié.

Les clés API restent dans les secrets GitHub de ton dépôt, jamais dans le code.

Contact : ouvre une issue sur le dépôt GitHub du projet.
