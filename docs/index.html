youtube-automation

Logiciel open source : chaque personne l’installe sur son compte Google et sa propre chaîne YouTube. Il génère des vidéos (actualité et conseils) avec une IA, publie sur YouTube, et enregistre les clips conseils sur Google Drive.

Ce que fait l’application (sur le compte qui l’autorise)

  • Génère des YouTube Shorts (actualité mondiale + conseils).
  • Publie sur la chaîne YouTube liée au compte autorisé.
  • Enregistre uniquement les vidéos « conseils » dans un dossier Drive dédié.

Les clés API restent dans les secrets GitHub de ton dépôt, jamais dans le code.
